# Somali skills for the skill library

Run `python3 build.py` to produce `index_add.json` and `s/<id>.json`. Upload `s/*.json` to the public `skills` bucket, and merge `index_add.json` into `skills/index.json` (bump `v`, set `count`). Live since 2026-10-20 (index v2, 417 skills, category `somalia`).

Health and law here stay at the information level. Professional advice belongs to SubMac built-in bots.
